本文使用三个不同的状态：

- **已实现**：已有可执行代码或用户入口。
- **已自动验证**：已有规则、模型、属性、浏览器或整局回归证据；验证范围在对应记录中说明。
- **已人工验收**：按选定官方规则逐条复核，并有完整试玩记录。当前不能将方舟全牌库标为这一状态。

不以卡牌条目数推算整个项目完成百分比，也不将既有工时预算视为已投入工时。来源与发行条件的确认、规则复核和试玩分别跟踪。

## 3. 已实现功能的具体边界

### 3.1 核心、机制与内容表达

正式操作通过含命令 ID、操作者和修订号的命令信封提交。重复、过期、非法或结算异常的命令不会提交新状态；规则在克隆状态上执行，通过不变量检查后再提交。随机数显式保存在规则状态中，规则不依赖系统时间或 `Math.random()`。

存档保存初始配置、种子、版本、命令序列、快照与分支。导入时检查版本，从初始状态重放命令，再核对快照；当前没有自动升级旧规则存档。游戏配置、命令、状态和玩家视图保持各自的类型，网页适配器通过公共运行时连接规则与界面。

效果队列和待处理选择可以保存；刷新后继续未完成步骤，不重复扣费或发奖。事件按公开 / 指定玩家过滤。完整存档包含全局状态，是本地研究和复现文件；未来联机仍需要服务端权威状态和信息隔离。

原创卡牌支持 JSON 中的收益、抽牌、收入注册、顺序执行和选择等有限效果。未知效果类型在 schema 校验时失败。方舟的大量专属卡牌、能力、条件和时序仍由 TypeScript 模块实现，尚未做到全部通过通用 JSON 配置新游戏。

### 3.3 牌桌、信息与操作

已结合本地 BGA 录屏和 Steam 官方公开截图调整空间分配：中间为主地图，右侧为双方公开摘要及可收起市场，底部集中手牌 / 展示区、上下文目标、费用、确认与五行动。普通对局选择采用图标 / 文字按钮，地图建筑放置仍就地完成。

双方资金、休息收入、魅力、保护、声望、X、事务员、手牌数量与固定图标槽持续可见；收入和图标来源通过悬停 / 键盘聚焦展开。开局八张候选牌、三个公共动保及本人的终局目标同屏。对手观察入口只展示公开地图和已入园牌，返回后保留自己的选卡及建造草稿。

动物 / 赞助商条件、保护项目门槛关联缺口、图标来源和地图地形；水岩卡面计数与实际共边地形分别计算。地图有合法落点、跟随预览、点击锁定、R/F/Esc 和明确的岩石 / 贩售亭区分。五行动说明显示本次强度、X、I/II 差异及不可执行原因。

这些功能已有浏览器回归和桌面截图记录。完整新手引导、日志点击定位对象和按信息揭示边界设计的普通撤销仍待完善；当前的取消草稿和调试分支不等同于任意回合悔棋。见[底部操作台验收](steam-layout-and-console.md)、[同屏信息复查](bga-information-review.md)和[条件联动验收](decision-guide-acceptance.md)。

### 3.4 大厅、对局库、AI 与实验工具

当前大厅的游戏目录已与具体规则分离；浏览时不恢复全部历史局，继续某局才按 gameId 加载其适配器。每次新建 / 导入获得新的 matchId，相同游戏或种子不会覆盖旧局。大厅仍把游戏卡片和创建设置放在同页，离开后不保留设置草稿，主导航也尚未收敛为三个目的地。

IndexedDB 版本 2 将轻量摘要、原始存档和设置分开保存。新状态与摘要原子写入，写入串行并检查 writeVersion；旧 `current` / `ark-current` 幂等迁移，保留原文。Web Locks 限制同局一个写入者，其他标签只读，释放后可载入最新存档接管。保存失败冻结当前写入，仍可导出内存进度。

两款游戏均有本地 AI，通过和人类相同的命令入口行动，并使用各自玩家视图。离开牌桌、只读回放或切局会暂停旧局 AI。当前没有外部模型调用、策略选择、独立 Worker 或联网匹配；方舟部分 AI 分支仍依赖选择提示文本，后续应改用稳定的结构化决策标识。

现有工具可查看规则进度、导入本地参考卡库、查看 / 导出资产清单、独立测试地图放置、加载 Demo 选择 / 终局场景、回放和创建调试分支。Demo 回退或调试已经能创建新的实验副本；“从对局库复制任意对局”的统一入口尚未实现。网页也没有通用批量模拟面板。

### 3.5 资料、美术与公开构建

参考网站位于 `references/Next-Ark-Nova-Cards/`，保持独立仓库和 Git 忽略。导入器用 TypeScript AST 静态读取基础卡牌数据，记录来源提交、文件 SHA-256 和修正，不执行上游函数。完整参考结果保存在被忽略的 `content/private/`，独立于正式规则覆盖率。

本地开发 / 预览通过白名单接口读取已有动物、赞助商图片及图集；保护项目、图标、地形和建筑共登记 6 个图集、62 个区域。资源目录、内容哈希 URL、损坏图集共享回退与发行产物审计已实现。

公开 Pages 使用项目内置 SVG/CSS；没有将参考仓库、BGA 缓存或原作图片复制到公开构建。完整原作美术包的公开使用条件仍未确认。发布边界和具体来源见[素材清单](art-assets.md)与[体验及美术管线](experience-and-art-pipeline.md)。
