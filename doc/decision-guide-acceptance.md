# 条件联动与五行动说明

## 本次范围

延续录屏的信息可见性改进，把卡牌与保护项目的条件关联到公开图标、来源和地图；在底部五行动旁展示本次能力与 I／II 差异。对手园区快看、普通撤销与人工十局验收仍属于后续工作。

## 操作

- 选中动物或赞助商后，悬停／聚焦右侧条件图标，可以查看需要、已有与缺少数量；右侧本人摘要突出对应数字。自己的手牌不计作已入园来源。
- 来源说明列出相关动物、赞助商、合作动物园和大学。在“我的园区”标签中，关联的已入园卡牌也会高亮。悬停本人摘要的图标同样能查看和关联来源。
- 动物的水域、岩石条件关联所选饲养区的实际共边地形，只圈出当前查看的地形类别；绿色虚线表示同时满足容量与地形的安置区。右侧水岩卡面图标不会误用为地形条件。
- 容量按标准区、萌宠园、鸟禽馆和爬行馆分别检查；地图 2 的容量加成、群居与综合研究员的豁免沿用引擎规则。费用说明列出卡面、展示位费用与优惠，不预支打出后的收益。
- 公共基础保护项目，以及牌库中的数量收集项目，支持相同的图标缺口与来源说明。封锁、已占用、不同种类统计和协会／事务员要求分别提示；图标满足不等于可直接支持。放归与繁育项目继续使用对应条件说明和协会选择。
- 悬停／聚焦五行动，可以查看当前槽位、拟消耗 X、缠绕修正、本强度的 I／II 对照。执行中改为显示已经支付的 X 与剩余额度。不可执行的行动也可查看原因。
- 卡牌说明复用现有卡牌／动物行动表，区分普通抓弃与精选、动物数量和声望奖励、建筑面积、协会任务强度和工人、赞助商等级预算与拿钱。双重和毒液另作提示。

说明与联动均不提交游戏命令。移开、失焦或按 Esc 关闭；一次只显示一个说明浮层。确认操作、地图草稿、存档和回放协议保持原有流程。

## 实现约定

`cardRequirementChecks` 为卡面图标、升级、合作动物园和数值门槛提供结构化检查；`requirementError` 与界面共用这些结果，保持已有错误与规则判断。大型动物计划的一次减免按原规则分配，避免展示层另写一套判定。动物方向等其余规则继续由正式命令校验。

`ArkGuide` 只使用本人玩家视图与公开市场，维护临时关联状态；不保存对手秘密资料，也不写入对局。`iconSources` 只列出已入园来源。普通卡面保留紧凑信息和点击入口，实际条件在放大预览和详情中展开。

## 验收方法

1. 合法生成的起手中保留西伯利亚虎：查看亚洲条件的 3／0 缺口、本人高亮、对手不高亮；说明和聚焦不改变资源或修订。
2. 正常中局查看已入园图标来源，以及公共项目的门槛；退出说明后取消来源高亮。
3. 从正常建造流程得到同时邻水邻岩的五格区：查看岩石时只圈岩石，容量与费用分别说明，不把卡面水岩计数当作地形。
4. 动物行动不可用时仍能看 I／II；调整 X 只更新说明，真正开始后显示已支付 X 和剩余额度。
5. 继续检查开局留牌、三种桌面尺寸、建造／卡牌操作、AI、自动保存、回放与终局，确认浮层不会增加命令或破坏固定操作区。

以上属于自动回归与界面验收，不代替逐卡人工规则复核及十局人工完整试玩。
