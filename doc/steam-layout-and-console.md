BGA 录屏对应观察沿用 [同屏信息复查](bga-information-review.md)：右侧玩家资源 / 图标常驻、确认集中、建筑操作靠地图。本次优先解决用户截图中协会两层下拉、右栏纵向滚动和地图被多块面板压缩的问题。

宣传截图能支持空间分配与组件形式的判断，不能证明悬停、撤销、镜头运动或操作步骤的具体行为。本项目的分步选择、草稿锁定与可访问性是独立实现。

## 本次实现

1. 中央地图独占主要画幅；1366×768 起，主地图 SVG 高度至少占视口 40%。公共信息面板从地图右上展开，收起按钮原地保留。
2. 右侧只保留双方公开摘要和可收起市场；数据与图标持续可见。玩家摘要上有“观察园区”按钮，对手地图和已入园牌可查看，手牌与秘密目标不显示。
3. 底部操作台包括手牌 / 展示区切换、上下文选择、费用 / 确认区与五行动。所有普通对局选择都不再使用下拉框。地图放置仍在地图完成，底部负责建筑类型与确认。
4. 协会任务按“任务 → 目标 → 等级 → 放归（如需）→ 奖励 → 通配（如需）→ 确认”展开，每步用图标 / 文字按钮。目标选择可回到前一步；只有最终确认才提交引擎命令。可选项直接来自引擎合法命令，保留来源、等级、放归动物、通配及奖励顺序。
5. 建筑类型列出面积和费用；饲养区列出容量及不可安置原因，并可直接点地图选择。普通奖励选择仍保持完整候选项，不省略特殊能力的选择。
6. 观察对手期间底部操作与地图放置不可执行，回到自己的园区后建筑位置、锁定状态、选卡与协会步骤保留。观察入口不修改对局修订。
7. 开局保持公共动保、个人目标、八张候选牌与底部确认同屏；使用独立高度分配，避免复用中局布局裁切第二排卡牌。

## 验收与边界

- 覆盖 1366×768、1440×900、1920×1080：地图、手牌 / 展示区、五行动和确认在视口内，页面无整页滚动。
- 验证协会合作大洲图标、项目等级、放归动物、奖励选择与提交；过程中不提前消耗事务员或费用。
- 验证面板展开 / 收起，观察对手前后建造草稿不变，返回后可继续确认。
- 既有免费 / 独有建筑、群居、选择恢复、条件联动、AI、保存与终局继续跑回归。

Steam 与 BGA 图像仅作公开页面 / 本地录屏观察。本次没有复制 Steam 美术或新增原作图像到发布物；已有本地参考图集与公开自有矢量回退继续遵循资产发布清单。
