## 实施范围

- 鸟禽馆与爬行馆：5 格建筑、建造 II、每种每人一座；卡面特殊空间数独立于标准饲养区面积，0 空间动物也须满足地形。
- 一次性转移：只在建成当下逐只决定；恢复符合完整条件的最小占用标准区，没有则只按面积找最小区；不重复付费或领取动物收益。
- 20 张牌库保护项目：10 放归、5 繁育、5 收集。通过协会从手牌打出并立即支持，协会 II 可从声望范围内展示区打出并先支付费用。
- 动态项目区：双人最多两张，从左侧入场、向右推移，第三张进入弃牌堆；基础项目不移动。被移出项目的标记返回供应区，不恢复已使用的边缘奖励。
- 放归：4–5、3、1–2 三种面积等级精确对应；退还卡面印刷魅力，保护、声望和额外能力收益保留；动物及其育儿袋卡进入弃牌堆。
- 随机保护奖励：种子洗混九种奖励，每局选四块放在 5／8 点；双方共享且只能各取一次，5 资金选项始终存在。移除固定教学配置。
- 双重：原槽位强度执行两次，X 分别支付，两次后才移动卡牌并结算“行动完成后”；休息仍在整个回合后；未用标记在休息移除。也可用双重改拿最多两枚 X。
- 地图 0：独立地形、升级限制、覆盖奖励和边缘奖励；无起始建筑，首座须触及边界；创建、保存、恢复、规则页和 AI 均使用所选地图。
- 官方术语表核对时修正了已入池赞助商 203、209、220、225、229、230、261 的缺失即时或终局效果。

牌库覆盖：77 动物 + 18 赞助商 + 20 牌库项目 + 12 基础项目 + 11 终局卡 = 138 / 235。没有把未实现动物与赞助商加入牌库。

## 规则依据与核对决策

本地中文规则 PDF 第 12、15–16 页、参考项目的地图 0 原图与建筑说明图，以及以下出版社资料：

- https://www.feuerland-spiele.de/fileadmin/game/Arche_Nova/AN_Glossar_DE_22_10_Web.pdf
- https://capstone-games.com/products/ark-nova 页面公布的官方英文 Glossary、Icon Overview 和 FAQ。
- https://cdn.shopify.com/s/files/1/0947/3907/1278/files/Ark-Nova-Glossary.pdf?v=1754428544
- https://cdn.shopify.com/s/files/1/0947/3907/1278/files/Ark-Nova-FAQ-v2.pdf?v=1754428544

原文件保存在被忽略的 `.artifacts/ark-reference/`，不纳入仓库或公开发行物。

规则决策：

1. 放归不是任意“至少 X 格”：中间等级必须恰好是 3 格，右侧是 1–2，左侧是 4–5。
2. 放归可进特殊馆的动物时，只要能移除相应空间标记，就优先移除；并不要求它历史上确实安置在那座馆。
3. 因此建筑占用数为规范状态，动物名称仅作辅助标签；不强制所有动物始终与历史建筑一一绑定。官方接受极少数无法重新逐一分配动物的情况。
4. 放归育儿袋动物也弃除压在其下的卡牌，但不回退育儿袋已获得的魅力。
5. 两次双重行动的增强 X 不通用；完成后效果要等整个双重行动结束。
6. 地图 0 左侧对应地图 A 的“立即和休息 +5 资金”位置改为“立即雇佣事务员”。
