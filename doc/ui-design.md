# 参考录屏后的界面设计

参考：用户提供的 `doc/方舟动物园录屏.gif`，1915×906，共 10,841 帧。抽取 0、600、2400、5000、8000 帧，查看公共市场、手牌、协会区域和建筑放置等状态。抽取结果在本地 `.artifacts/reference/`，不公开分发原作画面。

## 观察与改进

| 观察到的操作负担 | 本次采用的设计 |
|---|---|
| 地图、手牌和行动区域纵向分布，部分操作需要滚动找位置 | 主桌分区；当前操作固定在底部；参考信息独立导航 |
| 同屏纹理、图标、色块与原尺寸卡牌信息密集 | 米白与植物绿为主，弱化边框和纹理，文字与资源有稳定层级 |
| 小卡牌上的效果与费用需要放大辨认 | 卡牌点击后在固定详情区展示全文、总费用和可执行原因 |
| 放置建筑时旋转按钮、确认和地图位置分散 | 地图旁的规划面板集中面积、旋转、镜像、费用和确认 |
| 颜色提示不足以解释为什么不能落子 | 同时显示文字原因：边界、重叠、邻接、连通和资金不足 |
| 对局历史与即时决策争夺空间 | 日志限制高度，操作区优先展示当前选择，可进入只读历史回放 |

## 已实现交互

原创牌桌使用公共展示区、自己的手牌、已建设区域和对手公开摘要。卡牌采用自制 SVG 植物插画，无第三方图片、远程字体或网络依赖。

桌面提供「专注牌桌」切换，收起介绍区，为市场、手牌与操作留出空间；该设置不影响对局规则或存档。

所有建设先选卡再确认，非法行动展示原因。选择效果在操作区持续显示，刷新会恢复选择。玩家固定操作自己的座位，其他座位由简单 AI 自动操作，AI 手牌和私密日志保持隐藏。完整存档明确标注包含隐藏信息。

默认进入统一创建页，Demo 选择 2–4 人，方舟限定双人并可选择地图 A / 0，均支持 AI。在线匹配禁用并标明暂未开放。创建页提供规则入口与继续已保存对局，两款游戏分槽存档。

独立规则页以目标、初始资源、三种行动、结算流程、收入和 AI 对战分区说明。AI 思考时操作区明确显示当前 AI，禁止人类代操作；阅读规则和回放会暂停 AI。

「建造交互实验」采用自制地图，不宣称是官方地图 A/0。可点击或键盘选格，旋转、镜像和费用实时预览；绿色与红色同时配合文字提示。确认后扣费，撤销返还该次费用。

## 方舟首个可玩版

方舟牌桌沿用录屏中的分区：上方双向计分、声望与休息轨道和 6 张公共展示牌，中部地图 A、协会和详情，下方手牌、秘密终局卡与固定五行动。项目显示双人封锁和占用。

地图 A / 0 按各自原图逐格编码，以 SVG 重绘水域、岩石、奖励、起始建筑和升级限制格。多格建筑绘制整块外轮廓。特殊馆显示真实占用／容量，动物名称仅作辅助标签；放归按原作的最小占用区和特殊馆标记规则处理。预览展示实际费用、剩余资金与非法原因。

选择建造/动物/赞助商后自动定位到地图与详情；卡牌行动定位到市场，协会行动定位到协会。动物与赞助商可从地图旁的快捷手牌区选择，减少在地图和底部手牌之间滚动。五行动始终留在视口底部。

本地预览读取参考目录中的卡图，静态发行物仅保留独立卡面与规范化数值，不打包上游原图。源目录不可用时卡面回退到图标，操作流程仍可使用。

阶段三新增牌库项目区域，显示双人两张上限、入场推移、放归和繁育条件、等级占用；协会按钮明确显示手牌／展示区来源、放归动物与边缘奖励，并可切换奖励先后顺序。

保护 5/8 点展示本局随机四块奖励及领取状态。双重标记显示在行动卡上，第二次操作单独选择 X 花费。特殊馆建成后的逐只转移使用可恢复选择面板，跳过后不再开放随意转移。

未入池动物和赞助商不出现；剩余差异在支持范围与规则页中明确列出。
