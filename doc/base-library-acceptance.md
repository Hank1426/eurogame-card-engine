## 主要实现

- 群居：可复用已有同等或更大卡面面积的食草动物；可选择普通饲养区，放归仍按标准最小占用区处理。
- 额外行动：动物卡先归位，再执行指定行动或决心。继续队列嵌入同一回合，额外行动完成前不结算休息或切换座位。
- 坚韧：抽两张终局卡选一张。首次十保护仅弃一张目标，其余保留；后续获得的目标也可共同计分。
- 主张／支配：从真实基础项目储备取得卡牌，通过协会打出并支持；牌区守恒同时覆盖场下储备与场上基础项目。
- 开屏：免费鸟禽馆豁免建造 II 的特殊馆门槛，但不豁免地图建造 II 格，仍有一次性转移。
- 毒液：最低槽标记随行动移动，执行对应卡或替代 X 可移除；未移除则回合末支付 2。资金不足按规则撤销整回合，恢复随机数、牌区和资源，同时保留回退命令用于重放。
- 缠绕：按对手领先的魅力／保护轨道数影响最高槽行动，强度减 2；低槽不足 1 时须用 X 或替代；双重仍按降低后的基础强度执行。
- 偷窃：影响对象由公开轨道与免疫确定，由被影响者选择资金或随机手牌；随机使用显式 RNG，具体卡名只向相关座位显示。
- 催眠：在能力时序点锁定对象，动物行动后选择对方槽位 1–3 的卡。使用对方卡面等级、槽位与标记，自己的资源和园区；完成后移动对方卡，不使用对方双重。
- 十五种独有建筑：3/4/2 格形状、地形和边界约束、不可镜像、供应唯一。牌未打出前检查合法位置；等待结算的强制建筑不能被其他放置堵死。
- 其余赞助商：通配标记、工程师、综合研究员、考古学家、专利、重复放归、大小方向、小型额外安置、首次图标收益、条件豁免，以及连接／孤立／空地组和建筑收入计分。
- 工作台：群居选项、毒液／缠绕标记、受影响玩家选择、额外行动、通配标记、独有建筑及工程师地图放置均可操作。
