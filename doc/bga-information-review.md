# 录屏复查：同屏信息与操作效率

本次针对本地 `doc/方舟动物园录屏.gif`（1915×906，10,841 帧）复查 600、750、1000、1400、1800、2400、5000、8000 帧。750、1800 帧补取原尺寸；其余使用原尺寸帧与开局连续抽帧联系表。下表区分实际观察与本项目的设计取舍，不声称逐帧分析或在线 BGA 实测。

## 观察与落地

| 录屏证据 | 对决策的作用 | 本次实现 |
|---|---|---|
| 600、2400、5000：右侧同时排列两名玩家的资源、分数、行动缩略与图标计数 | 无须切换园区就能比较双方，判断卡牌和项目条件 | 右侧常驻双方公开摘要，切换中部标签、AI 行动与回放均保留 |
| 5000：已有图标显色，未有图标以淡色保留原位置 | 避免图标出现、消失导致读数位置变化 | 五大洲、研究、水域、岩石、七类动物共 15 个槽位；零值淡化，始终显示 |
| 750：八张起手牌可以多选，已留牌有勾选，顶部明确要求保留四张 | 选择可以反复调整，确认前不提交 | 保留既有多选与固定确认，补充公共动保和自己的终局目标常驻参考 |
| 750、1000：展示区尚未翻开，参考内容与选牌同时可见 | 留牌阶段需要目标信息，多于尚未开放的市场信息 | 开局上方空市场替换为三个公共动保与两张个人终局卡；开局结束恢复市场 |
| 2400、5000：操作提示描述当前必须执行的动作 | 玩家知道下一步做什么 | 保留状态提示与固定操作栏；留牌提示明确先参考目标再确认 |
| 8000：地图上有旋转控件、红色建筑轮廓和确认符号 | 放置与调整靠近操作对象，非法位置有即时反馈 | 保留已实现的地图跟随预览、合法落点、点击锁定、R/F/Esc；不把长坐标列表搬回界面 |
| 1800：抽牌前提示无法在此后悔棋，并提供返回上一步、重新开始回合 | 信息揭示是撤销的重要边界 | 本次不新增普通撤销；继续保留有分支标识的调试回放。正式撤销须按信息揭示与跨玩家选择边界另行设计 |
| 8000：日志中的历史操作带有返回入口；页面滚动后部分上方信息离开屏幕 | 记录可用于复盘，但纵向铺开仍有操作成本 | 保留折叠日志和固定右侧确认区；桌面不新增整页滚动来容纳摘要 |

录屏中未直接展示的悬浮细节不作为事实描述。本项目将悬浮说明作为节省空间的设计补充：数字始终可见，解释按需出现。

## 信息层级

- 常驻主资源：双方当前资金、当前休息资金收入、魅力、保护。
- 常驻次资源：声望、X、可用 / 已解锁事务员、手牌数量。
- 常驻图标：大洲、研究与水岩卡面图标、七类动物。水岩统计来自卡牌，不把地图地形误算为图标。
- 悬浮 / 键盘聚焦：收入来源、额外保护与 X 收入、可选精选与赞助商收入效果、图标来源、玩家行动顺序 / 升级、合作动物园与大学。
- 开局目标：公共动保各档图标门槛、保护奖励、双人封锁；个人终局目标的计分门槛和说明。

双方摘要复用原操作栏宽度，不新增侧栏。开局已选牌改为可取消的紧凑名称条，把原重复牌面的空间归还八张候选牌，避免小桌面第二排卡牌被裁切。常驻信息采用图标加数字，不铺开说明文字；长来源清单可在浮层内滚动。浮层通过 portal 显示，避免被操作栏裁切，支持聚焦、Esc、移开关闭；打开说明不提交命令或增加修订号。

## 计算、可见性与素材

`breakIncome` 是引擎结算和 UI 预览共同使用的纯函数，资金包含魅力、贩售亭、侧门、资助类赞助商、政府拨款和已激活项目奖励。额外保护 / X、精选和付费赞助商机会在悬浮说明中列出；后续选择可能产生的收益不提前估入。保留原引擎结算事件顺序，存档协议与规则版本不变。

摘要只接收 `getPlayerView` 结果。对手只显示手牌数量，不显示手牌、秘密终局卡或牌库顺序。自己的开局终局目标直接读取本人视图。

所有图标经过已有 `ArkIcon` 图集入口：本地已有参考图标优先，缺少的图标使用项目矢量符号；没有下载或生成新的原作素材。公开构建继续遵循已有资产发布清单，不把未确认发布条件的参考图片打包上线。

## 后续可借鉴的操作，按收益排序

1. **对手园区快速查看**：目前可悬停玩家名看行动顺序、大学和合作动物园，仍需中部标签查看完整已打出卡牌。可增加玩家名点击切换园区，并保留当前操作草稿。
2. **需求与来源联动（已实现）**：悬停卡牌条件或动保图标时，联动高亮右侧对应计数与已入园来源，减少数图标的记忆负担。见[条件联动验收](decision-guide-acceptance.md)。
3. **行动表的就地解释（已实现）**：五行动悬浮层显示当前强度的具体能力、I/II 差异、X 成本，以及不可执行原因；执行中显示实际额度，减少跳转规则页。
4. **可撤销的操作草稿**：对尚未揭示随机信息的选卡、支付、地图预览统一提供取消草稿；普通回合撤销应先设计隐藏信息边界，不直接套用调试回退。
5. **日志对象定位**：点击收益中的卡牌或建筑可跳到对应对象；保留日志的折叠状态，避免日志挤占日常操作区。

## 验收

浏览器回归覆盖 1366×768、1440×900、1920×1080：开局三个公共动保、个人终局目标、八张候选牌、双方摘要和确认按钮均在视口内；确认后恢复展示区。中局核对双方公开计数与完整收入，切换公共信息标签后摘要仍可见；悬停 / 聚焦与 Esc 不改变对局修订。

截图由 `pnpm ui:capture:ark` 保存到本地 `.artifacts/ui/ark-setup-{宽度}.png`、`ark-inspector-{宽度}.png` 和 `ark-income-detail.png`。自动测试和截图验证 UI 与既有规则回归，不能代替逐卡人工规则复核。
